## Usage

```ts
import "@tecton/wc/input-otp"
```

```html
<tec-input-otp name="code" maxlength="6" pattern="digits" aria-label="Verification code">
  <tec-input-otp-group>
    <tec-input-otp-slot></tec-input-otp-slot>
    <tec-input-otp-slot></tec-input-otp-slot>
    <tec-input-otp-slot></tec-input-otp-slot>
  </tec-input-otp-group>
  <tec-input-otp-separator></tec-input-otp-separator>
  <tec-input-otp-group>
    <tec-input-otp-slot></tec-input-otp-slot>
    <tec-input-otp-slot></tec-input-otp-slot>
    <tec-input-otp-slot></tec-input-otp-slot>
  </tec-input-otp-group>
</tec-input-otp>
```

One real, transparent `<input>` covers the slots and holds the code, so typing, deleting, the arrow keys, paste, the virtual keyboard and one-time-code autofill work as in a text field; the slots display it. Slots take their position from their order (set `index` to override), and `maxlength` defaults to the number of slots.

## Pattern

`pattern` restricts the characters: `digits` (also opens the numeric keypad), `letters`, `alphanumeric`, or a regular expression every partial value must match (`[0-9A-F]*`). Characters that do not match are rejected; spaces in a pasted code are removed.

## Accessibility

- Assistive technology sees one text field with the whole code as its value; the groups, slots and separators are hidden from it.
- Name it like any control: a `tec-field-label` in a `tec-field`, `<tec-label for>`, `<label for>`, the `label` attribute or `aria-label`.
- `autocomplete="one-time-code"` (the default) lets browsers and phones offer a code received by SMS or email.

## Usage guidelines

### Use it when

- A one-time code from email, SMS or an authenticator app.
- A short fixed-length PIN the user reads from somewhere and types once.
- The value has a known length and every character deserves its own box.

### Not for

- a password, a token or any other free-form value: use [Input](/docs/components/input)
- a field with an icon or a button attached: use [Input Group](/docs/components/input-group)
- the label, description and error message around the code: use [Field](/docs/components/field)

### Do

<DoList>

<Do>

Write one `tec-input-otp-slot` per character; `maxlength` defaults to their number.

</Do>

<Do>

Read `value` on `input`, or wait for `tec-complete`; set the initial code with the `value` attribute.

</Do>

<Do>

Restrict the alphabet with `pattern="digits"` or `pattern="alphanumeric"`.

</Do>

<Do>

Split long codes with `tec-input-otp-group` and `tec-input-otp-separator`, and mark errors with `invalid` on the OTP input.

</Do>

<Do>

Put it in a `tec-field` with a `tec-field-label`, and disable it with `disabled`.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Repeating explicit slot indexes in each group">

<Wrong>

```html
<tec-input-otp maxlength="4" aria-label="PIN">
  <tec-input-otp-group><tec-input-otp-slot index="0"></tec-input-otp-slot><tec-input-otp-slot index="1"></tec-input-otp-slot></tec-input-otp-group>
  <tec-input-otp-group><tec-input-otp-slot index="0"></tec-input-otp-slot><tec-input-otp-slot index="1"></tec-input-otp-slot></tec-input-otp-group>
</tec-input-otp>
```

</Wrong>

<Correct>

```html
<tec-input-otp maxlength="4" aria-label="PIN">
  <tec-input-otp-group><tec-input-otp-slot></tec-input-otp-slot><tec-input-otp-slot></tec-input-otp-slot></tec-input-otp-group>
  <tec-input-otp-group><tec-input-otp-slot></tec-input-otp-slot><tec-input-otp-slot></tec-input-otp-slot></tec-input-otp-group>
</tec-input-otp>
```

</Correct>

`index` addresses a character of the whole code, so repeated indexes show the first characters twice and the rest is never displayed. Leave it out: slots number themselves in order.

</Dont>

<Dont severity="MEDIUM" title="One input per character">

<Wrong>

```html
<div class="flex gap-2">
  <tec-input maxlength="1" aria-label="Digit 1"></tec-input>
  <tec-input maxlength="1" aria-label="Digit 2"></tec-input>
</div>
```

</Wrong>

<Correct>

```html
<tec-input-otp maxlength="2" aria-label="Code">
  <tec-input-otp-group><tec-input-otp-slot></tec-input-otp-slot><tec-input-otp-slot></tec-input-otp-slot></tec-input-otp-group>
</tec-input-otp>
```

</Correct>

Separate inputs break paste and autofill, add a tab stop per character and are announced as unrelated fields.

</Dont>
