These pages document the components of the shadcn/ui vocabulary as web components: the same component set, parts, variants and sizes, with HTML-native APIs — attributes for configuration, properties for state and data, slots for content and standard events. The Tecton variants (status colours on alerts and badges, divider emphasis on separators, the outline / filled / text field surfaces) are attributes of the same elements.

<Callout title="One import">
  `import "@tecton/wc"` registers every element; `import "@tecton/wc/<name>"` registers one family. See [Installation](/docs/installation).
</Callout>
