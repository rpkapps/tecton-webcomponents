## Installation

The utilities ship as CSS with `@tecton/wc`, in two flavours with the same class names. Load one of them.

**Plain CSS**, for any page (or `import "@tecton/wc/utilities.css"` from a bundled script, or a `<link rel="stylesheet">` to the file):

```css
@import "@tecton/wc/utilities.css";
```

**Tailwind CSS v4**, which adds variants (`md:scroll-fade-none`) and the size modifiers (`scroll-fade-24`):

```css
@import "tailwindcss";
@import "@tecton/wc/tailwind.css";
@import "@tecton/wc/tailwind-utilities.css";
```

## Usage

| Class | Styles |
| --- | --- |
| `scroll-fade` | `mask-image: var(--scroll-fade-mask, var(--scroll-fade-block));` <br /> `animation-timeline: scroll(self y);` |
| `scroll-fade-y` | Same as `scroll-fade`. |
| `scroll-fade-x` | `mask-image: var(--scroll-fade-mask, var(--scroll-fade-inline));` <br /> `animation-timeline: scroll(self inline);` |
| `scroll-fade-t` | Fade mask on the top edge. <br /> `animation-timeline: scroll(self y);` |
| `scroll-fade-b` | Fade mask on the bottom edge. <br /> `animation-timeline: scroll(self y);` |
| `scroll-fade-l` | Fade mask on the left edge. <br /> `animation-timeline: scroll(self x);` |
| `scroll-fade-r` | Fade mask on the right edge. <br /> `animation-timeline: scroll(self x);` |
| `scroll-fade-s` | Fade mask on the start edge, mirrors in RTL. <br /> `animation-timeline: scroll(self inline);` |
| `scroll-fade-e` | Fade mask on the end edge, mirrors in RTL. <br /> `animation-timeline: scroll(self inline);` |
| `scroll-fade-none` | `--scroll-fade-mask: none;` |
| `no-scrollbar` | Hides the scrollbar (`scrollbar-width: none`). |
| `scroll-fade-<number>` (Tailwind) | `--scroll-fade-size: calc(var(--spacing) * <number>);` |
| `scroll-fade-[<value>]` (Tailwind) | `--scroll-fade-size: <value>;` |
| `scroll-fade-{t,b,s,e}-<number>` (Tailwind) | `--scroll-fade-{t,b,s,e}-size: calc(var(--spacing) * <number>);` |
| `scroll-fade-{t,b,s,e}-[<value>]` (Tailwind) | `--scroll-fade-{t,b,s,e}-size: <value>;` |

| Custom property | Default | Description |
| --- | --- | --- |
| `--scroll-fade-size` | `min(12%, 2.5rem)` | Depth of every fade. |
| `--scroll-fade-t-size`, `--scroll-fade-b-size`, `--scroll-fade-s-size`, `--scroll-fade-e-size` | `--scroll-fade-size` | Depth of one edge. |
| `--scroll-fade-reveal` | `6rem` | Scroll distance over which a fade eases in or out. |

Add `scroll-fade` or `scroll-fade-y` to the scroll container, i.e. the element that has `overflow-y: auto`.

```html
<div class="scroll-fade" style="overflow-y: auto">…</div>
```

The fade is scroll-aware and tracks the scroll position:

- At rest, the top edge is crisp and the bottom edge fades to hint at more content.
- As you scroll, a fade appears at the top and both edges stay faded mid-scroll.
- At the end, the bottom edge sharpens to show you have reached the last item.

The fade is applied with `mask-image`, so it dissolves the content itself rather than overlaying a colour. The mask uses a linear fade from transparent to black, so it adapts to any background without configuration. If your scroll area sits inside a card, put the background and border on a wrapper and `scroll-fade` on the inner scroller, so the fade dissolves the content and not the card.

## No Overflow, No Fade

If the content does not overflow, no fade is shown. You can apply `scroll-fade` to any list without checking whether it scrolls.

## Horizontal Scrolling

Use `scroll-fade-x` on containers that scroll horizontally, i.e. the element that has `overflow-x: auto`.

<ComponentPreview name="scroll-fade-horizontal" class="h-64" />

```html
<div class="flex scroll-fade-x overflow-x-auto">…</div>
```

The horizontal fade is direction-aware. In RTL layouts, the crisp edge and the fade follow the reading direction with no extra classes needed. The size properties and `scroll-fade-none` work the same for both axes.

## Edge Fades

Use edge utilities when only one edge should track the scroll position.

<ComponentPreview name="scroll-fade-edge" />

```html
<div class="scroll-fade-b overflow-y-auto">…</div>
```

The edge utilities are scroll-aware. Start edges fade in after you scroll away from the start, and end edges fade out when you reach the end. Use `scroll-fade-t`, `scroll-fade-b`, `scroll-fade-l` and `scroll-fade-r` for physical edges. Use `scroll-fade-s` and `scroll-fade-e` for logical inline edges that mirror in RTL.

## Fade Size

The fade depth defaults to `12%` of the container, capped at `40px` so tall scrollers stay subtle. Set `--scroll-fade-size` for a fixed depth; with Tailwind, `scroll-fade-<number>` does the same on the spacing scale.

<ComponentPreview name="scroll-fade-size" />

```html
<!-- Plain CSS -->
<div class="scroll-fade" style="overflow-y: auto; --scroll-fade-size: 6rem">…</div>

<!-- Tailwind -->
<div class="scroll-fade overflow-y-auto scroll-fade-24">…</div>
<div class="scroll-fade overflow-y-auto scroll-fade-[15%]">…</div>
```

To fade opposite edges by different amounts, set the per-edge properties `--scroll-fade-t-size`, `--scroll-fade-b-size`, `--scroll-fade-s-size` and `--scroll-fade-e-size` (Tailwind: `scroll-fade-t-<number>`, `scroll-fade-b-<number>`, `scroll-fade-s-<number>`, `scroll-fade-e-<number>`). They override the overall size on the edge they target. Use the logical `s`/`e` sizes for horizontal scrollers so they mirror in RTL.

```html
<div class="scroll-fade overflow-y-auto scroll-fade-b-8 scroll-fade-t-2">…</div>
```

The fade eases in and out over a fixed scroll distance rather than appearing instantly. That distance is `--scroll-fade-reveal`, `96px` by default and independent of the fade depth. Lower it for a snappier reveal or raise it for a more gradual one:

```html
<div class="scroll-fade overflow-y-auto" style="--scroll-fade-reveal: 64px">…</div>
```

## Disabling the Fade

Use `scroll-fade-none` to remove the fade. It works in any class order, so the typical use is responsive or stateful (`md:scroll-fade-none` with Tailwind):

```html
<div class="scroll-fade overflow-y-auto md:scroll-fade-none">…</div>
```

## Fallback

The scroll-aware behaviour is implemented with [CSS scroll-driven animations](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations), with no JavaScript and no scroll listeners. In browsers that do not support scroll-driven animations, `scroll-fade` falls back to a static fade on both edges, and edge utilities fall back to a static fade on the selected edge.

Since the mask is applied to the scroll container itself, a visible scrollbar fades with the content at the edges. Pair `scroll-fade` with `no-scrollbar` (or Tailwind's `scrollbar-none`) if you want to hide the scrollbar entirely.

## Inside shadow roots

The classes are global CSS, so they style your own (light DOM) markup, including content you slot into Tecton elements. Scroll containers inside a component's shadow root are styled by that component.

## RTL

`scroll-fade-x` follows the reading direction (`:dir(rtl)`). At rest, the start edge is crisp and the end edge fades. In RTL layouts that means a crisp right edge and a fade on the left, mirrored from LTR.

## Accessibility

- The fade is purely visual: the content keeps its semantics and remains fully readable by assistive technology and keyboard scrolling.
- A faded edge is a hint, not the only cue: keep scrollable regions keyboard-focusable (a `tabindex="0"` on the scroller when it contains nothing focusable) and labelled when they are landmarks.
- Hiding the scrollbar (`no-scrollbar`) removes a visible affordance; keep it for short lists where the fade already signals more content.
